栈 vs 队列：取出的顺序为什么不同？

两个容器同时按 1 → 2 → 3 的顺序加入数据。点击下面的按钮，亲眼观察 后进先出（LIFO） 和 先进先出（FIFO）。

栈 Stack

像一摞盘子：最后放的，最先拿

LIFO 后进先出
只能从栈顶放入 / 取出
↑
下次取出：3st.top() → 3

队列 Queue

像排队买票：先来的人，先离开

FIFO 先进先出
← 从队头取出，队尾加入 ←
← 队头 front队尾 back ←
下次取出：1q.front() → 1

操作实验

试试「同时取出」：栈会取出 3，而队列会取出 1。

栈：push / pop / top队列：push / pop / front / back基本操作：O(1)

C++ 小提示：std::stack 与 std::queue 都是容器适配器；pop() 只移除元素，不返回移除的值。这个实验采用相同的输入顺序，以便比较访问规则，而不是比较底层内存结构。
